# 联锁梁几何参考：7.2.2.5483 Release

Bug 18042 要求材料交界形成细长交错榫卯。用户指定的 7.2.2 正常版本与同一附件的本地异常版本都能通过旧的 Gap infill / 墙类型计数规则，因此此处比较实际挤出的外墙轮廓，计数不再作为联锁梁通过条件。

## 覆盖范围

`interlocking_7_2_2.json` 包含六类参数的 19 个用例参考：原有 17 项，以及 Bug 四色拼块的开启、关闭两项。每个参考绑定明确的用例 ID、预期值、输入 3MF SHA256 和参考 G-code SHA256。参数 JSON 通过 `geometry_baseline` 显式选择参考，未知参考、值不符、层高缺失或几何为空均失败。

保留配置检查作为前置条件。宽度、方向、层数、深度和边界避让用例还要求 `interlocking_beam` 开启，防止关闭时只凭配置值通过。函数继续返回 `(ok, actual_config_value, details)`；细节报告包含实际不匹配的层、材料和坐标。`mmu_segmented_region_max_width` 的两项检查未改变。

## 几何规则与限制

- 只读取正挤出的 `Outer wall`，按真实层和工具区分。普通填充、支撑、擦拭塔、空移不参与。兼容 `;Z:` / `;:` 层高、M82/M83、G90/G91、G92 及 I/J 圆弧。模型外墙遇到不支持的 R 圆弧明确失败，不按直线处理。
- 核对全部层数、层高，并比较十个参考层：1/4、3/4 高度，以及中部连续八层。当前用例梁层数为 1/2/3，八层覆盖其 2/4/6 层周期。非采样层的局部几何缺陷可能不被检测，不能将该检查称为全层几何等价。
- 对每层每个材料分别双向比较外墙路径，既拒绝缺失的榫齿，也拒绝额外的路径、材料错配和层间错位。改变路径顺序、起点或直线分段不影响比较。
- 路径按不超过 0.1 mm 间隔取样，计算样本点到另一组线段的实际距离；所有样本必须在 0.08 mm 内。该容差用于坐标量化、接缝小缺口与圆弧离散，明显小于本套用例最小 0.5 mm 梁宽。没有全局长度百分比放宽，也不根据被测输出自动扩大范围。
- 比较的是特定模型、特定参数对应的正确轮廓，不是通用“榫卯识别器”，也不把墙段数量推算成梁宽。模型位移、轮廓策略或喷嘴条件有意变化时，应复核正确几何后更新相应参考。只改配置但不生成对应几何应失败。
